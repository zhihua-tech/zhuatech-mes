# 企业级不合格品处置治理

`POST /api/enterprise/mes/nonconformance-disposition` 用于不合格报告（NCR）形成后的让步接收、返工、报废和退供应商决策。

系统检查批次隔离、遏制措施、影响范围追溯、处置数量、材料评审、客户让步、返工作业指导书、报废或退货授权、库存移动以及电子签名。结果返回 `EXECUTE / REVIEW / BLOCKED`、审批路径和缺失证据，确保不合格品不会在未受控状态下重新流入生产或发运。
